1. Programming
Java, collections, exceptions, multithreading.
2. OOP
Encapsulation, abstraction, inheritance, polymorphism.
3. Principles
SOLID, DRY, KISS, YAGNI.
4. Patterns
GoF: creational, structural, behavioral.
5. Application Design
MVC, layered, clean, hexagonal, monolith, microservices, event-driven.
6. System Design
Communication, scalability, data, distributed systems, security, monitoring, trade-offs.
7. Infrastructure
Docker, Kubernetes, cloud, CI/CD, monitoring, logging.
8. Deep Dives
NLB vs ALB, load balancing, indexing, architecture principles vs patterns.

Example  1:  "No  Single  Point  of  Failure"  Principle:  If  one  component  fails,  the  whole  system  should  not  stop.   In  Java:
Source page 21 
Instead  of:  Application     |  Database  Server   Use:  Application     |  Primary  Database     |  Replica  Database  If  one  database  goes  down,  another  can  take  over.   Example  2:  "SaaS  is  Preferred"  like  AWS  services   Principle:  Use  existing  cloud  services  instead  of  building  everything  yourself.  Instead  of  writing  your  own  email  service  in  Java:  public  class  EmailService  {     //  thousands  of  lines  of  code  }  Use  a  SaaS  provider  like:  SendGrid  Mailchimp  Your  Java  code  simply  calls  their  API.   Example  3:  "Best-of-Breed  Applications"  Principle:  Choose  the  best  tool  for  each  job.   Example:  Java  Spring  Boot  for  backend  PostgreSQL  for  data  Redis  for  caching  Kafka  for  messaging  Each  tool  is  selected  because  it  excels  at  a  specific  task.
